# Launch checklist

## Required before public launch
- [ ] Confirm final homepage copy and CTA language
- [ ] Replace founder portrait placeholders with approved photography
- [ ] Add permitted reference-client / brand names or remove the placeholder block
- [ ] Add only verified case-study metrics when permissions are available
- [ ] Choose booking flow: contact form only, Calendly, Cal.com, HubSpot Meetings, etc.
- [ ] Configure contact form delivery and test end-to-end
- [ ] Decide whether www or apex (`thegrowthmachine.co`) is canonical
- [ ] Connect Vercel to GoDaddy DNS
- [ ] Preserve any GoDaddy MX/email DNS records
- [ ] Add analytics (GA4 or preferred stack) and conversion events
- [ ] Add Search Console after domain verification
- [ ] Add privacy policy / cookie controls if analytics or marketing pixels require them
- [ ] QA on iPhone Safari, Android Chrome, desktop Safari/Chrome/Edge
